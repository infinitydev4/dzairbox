# Référentiel local DZ-2026-69-v1

Source des données et licence MIT : https://github.com/riadh2002/algeria-69-wilayas-1541-communes (fichiers data/wilayas.json et data/communes.json, récupérés le 24 octobre 2026).

69 wilayas, 1 541 communes. Noms français/arabe, rattachements de 2026 et points de communes. Le champ `id` est l'identifiant stable du jeu de données, pas un code administratif officiel inventé. Les points de communes sont des positions approximatives : ils ne désignent jamais l'établissement d'un professionnel.

Références officielles : ONS, https://www.ons.dz/IMG/pdf/code_geo_2021.pdf ; organisation territoriale 2026, Journal officiel n° 25 du 5 avril 2026 et ministère : https://interieur.gov.dz/2026/05/17/le-ministre-de-linterieur-preside-une-reunion-de-coordination-pour-assurer-le-suivi-de-la-mise-en-place-des-onze-nouvelles-wilayas-et-des-preparatifs-logistiques-des-processus-electoraux-qui-sy-de/ . Le fichier de 2021 ne doit pas être utilisé seul pour les rattachements de 2026.

Les valeurs restent versionnées et remplaçables, sans plafond de wilayas codé dans l'interface. Aucune migration automatique des adresses libres existantes n'est effectuée.
